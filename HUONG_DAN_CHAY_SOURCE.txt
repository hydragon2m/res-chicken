======================================================================
   HƯỚNG DẪN CHẠY MÃ NGUỒN HỆ THỐNG CHICK RES QSR (DOCKER COMPOSE)
======================================================================

Toàn bộ hệ thống (PostgreSQL 16 + Tự động tạo bảng/Seed dữ liệu + Backend NestJS 11 + Frontend Next.js 16) đã được đóng gói sẵn trong Docker Compose. Bạn không cần cài đặt Node.js hay PostgreSQL rời trên máy.

----------------------------------------------------------------------
BƯỚC 1: CÀI ĐẶT CÔNG CỤ CẦN THIẾT
----------------------------------------------------------------------
1. Tải và cài đặt Docker Desktop:
   - Link tải: https://www.docker.com/products/docker-desktop/
   - Sau khi cài xong, mở ứng dụng Docker Desktop lên và đợi báo "Engine running".
2. Tải và cài đặt Git (nếu máy chưa có):
   - Link tải: https://git-scm.com/downloads

----------------------------------------------------------------------
BƯỚC 2: TẢI MÃ NGUỒN (CLONE GIT)
----------------------------------------------------------------------
Mở Terminal (hoặc PowerShell / Command Prompt trên Windows) và chạy lệnh:

   git clone https://github.com/hydragon2m/res-chicken.git
   cd res-chicken

(Tùy chọn) Tạo file cấu hình .env từ file mẫu (nếu bỏ qua bước này hệ thống vẫn tự dùng cấu hình mặc định):
   - Trên Windows (CMD/PowerShell):  copy .env.example .env
   - Trên macOS / Linux (Git Bash):  cp .env.example .env

----------------------------------------------------------------------
BƯỚC 3: KHỞI CHẠY TOÀN BỘ HỆ THỐNG BẰNG DOCKER COMPOSE
----------------------------------------------------------------------
Tại thư mục gốc của dự án (res-chicken), chạy duy nhất 1 lệnh:

   docker compose up -d --build

Lưu ý:
- Lần chạy đầu tiên sẽ mất khoảng 2 - 4 phút để tải image và build.
- Hệ thống sẽ tự động chạy theo thứ tự:
  1. Khởi tạo Database PostgreSQL 16 (cổng 5432)
  2. Tự động chạy Migration tạo 26 bảng và nạp sẵn dữ liệu 2 chi nhánh + 6 tài khoản mẫu
  3. Khởi chạy Backend API NestJS (cổng 3001)
  4. Khởi chạy Frontend Web Next.js (cổng 3000)

----------------------------------------------------------------------

----------------------------------------------------------------------
CÁC LỆNH QUẢN LÝ DOCKER HỮU ÍCH KHÁC
----------------------------------------------------------------------
- Xem trạng thái các container đang chạy:
  docker compose ps

- Xem log trực tiếp của hệ thống:
  docker compose logs -f

- Tắt hệ thống (giữ nguyên dữ liệu Database):
  docker compose down

- Tắt hệ thống và xóa sạch dữ liệu để làm mới từ đầu:
  docker compose down -v
